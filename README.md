# Snake Game for Android

Full-featured classic Snake game made with Kotlin.

## Features
- Swipe + On-screen D-pad controls
- 3 Difficulty levels (Easy / Medium / Hard)
- 5 Themes (Classic, Neon, Ocean, Sunset, Midnight)
- Local Leaderboard (Top 10)
- Score + High Score
- Increasing speed
- Pause / Resume
- Vibration + Sound feedback

## How to open
1. Download the project as ZIP
2. Open in Android Studio
3. Let Gradle sync
4. Run on a device or emulator
